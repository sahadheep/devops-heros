Task3 - journalctl
Objective

To understand how journalctl is used to view and filter system and service logs in Linux.

What is journalctl?

journalctl is a command-line utility used to view logs collected by the systemd journal. It helps in checking system events, errors, warnings, and logs generated by individual services.


Commands Practiced
1) journalctl --version (check journalctl version)
2) journalctl -n 20 (journalctl -n 20)
3) journalctl -p err -n 20 ( latest 20 error level log messages)
4) systemctl list-units --type=service --state=running (services currently running)
5) journalctl -u cron.service -n 20 ( latest 20 log entries)
6) journalctl --since "1 hour ago" ( journal entries during last hour)

Observation :
The commands were used to view general system logs, error logs, and logs related to the cron service. journalctl provides useful information for monitoring and troubleshooting Linux systems.

Conclusion : 
journalctl is useful for checking system and service logs. It can filter logs based on service, priority, and time, making it useful for debugging and system administration.
